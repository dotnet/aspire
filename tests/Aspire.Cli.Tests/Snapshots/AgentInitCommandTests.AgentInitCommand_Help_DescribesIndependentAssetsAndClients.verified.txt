Description:
  Configure independent assets for selected agents at project or global scope

Usage:
  Aspire.Cli.Tests agent init [options]

Options:
  --workspace-root <workspace-root>                                      Path to the workspace root directory
  --mcp <false|n|true|y>                                                 Configure the Aspire MCP server for selected agents (y/n or true/false; default: no)
  --playwright <false|n|true|y>                                          Install Playwright CLI and its skills for the selected agents (y/n or true/false; default: no)
  --dotnet-inspect <false|n|true|y>                                      Install the dotnet-inspect bootstrap skill for the selected agents (y/n or true/false; default: no)
  --aspire-skills <bundled|native|none>                                  Aspire skills source: bundled (copy all applicable skills), native (register the plugin/catalog), or none (default: bundled)
  --agents <all|claude|copilot|none|opencode>                            Comma-separated agent IDs (copilot,claude,opencode), 'all', or 'none'. Defaults to detected agents, or Copilot when none are detected
  --scope <global|project>                                               Configuration and skill scope: project or global (default: project)
  -?, -h, --help                                                         Show help and usage information
  -l, --log-level <Critical|Debug|Error|Information|None|Trace|Warning>  Set the minimum log level for console output (Trace, Debug, Information, Warning, Error, Critical)
  --non-interactive                                                      Run the command in non-interactive mode, disabling all interactive prompts and spinners
  --nologo                                                               Suppress the startup banner and telemetry notice
  --banner                                                               Display the animated Aspire CLI welcome banner
  --wait-for-debugger                                                    Wait for a debugger to attach before executing the command
